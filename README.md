# L’Entre-Deux — Prototype du site communal

Version de démonstration front-end (HTML, CSS, JavaScript), sans dépendance ni installation.

## Démarrage

Ouvrir `index.html` dans un navigateur, ou lancer un serveur local :

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Fonctionnalités

- Page d'accueil responsive inspirée de la maquette visuelle.
- Navigation par sections, recherche de démonstration.
- Modales pour rendez-vous, familles, démarches, paiements, participation et signalements.
- Formulaires interactifs **sans transmission ni stockage de données**.
- Lien externe vers le portail officiel PayFiP.

## Avant mise en production

Remplacer les images et le logo provisoires par les médias officiels autorisés. Valider les contenus et l'identité institutionnelle. Mettre en place les logiciels de réservation, les téléservices et les formulaires sécurisés ; prévoir RGPD, RGAA, sécurité, hébergement, mentions légales, gestion des cookies si nécessaire, back-office et tests utilisateurs.

Les dates, événements et informations de la maquette ne sont pas des annonces officielles.
